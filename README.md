# ReFitPROJ

Local watch app for revjmoney. Site: https://jmscnc.com

The phone build is an apktool tree under `FitPro-2.11.1-privacy-source`. The launcher name is ReFitPROJ. The Android package id is still `cn.xiaofengkj.fitpro` so a rebuild can replace the copy already on the phone.

Phone logs and the health database are not in this repo. Signing keys and rebuild output are not either.

Do not flash the watch from this tree unless that is the job in front of you.
